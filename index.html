01

憑證、HTTP、HTTPS、Port

🔐 網路安全與通訊

🔐 憑證 Certificate

憑證可以想成網站的「身分證」。 它可以幫助瀏覽器確認網站的身分， 並協助建立安全的 HTTPS 連線。

💡 簡單理解：
憑證就像網站的電子身分證， 用來證明網站是誰。

📨 HTTP

HTTP 是 HyperText Transfer Protocol。 它是一種讓瀏覽器和網站伺服器互相溝通的協定。

🔒 HTTPS

HTTPS 是比較安全的 HTTP。 它使用 TLS 加密資料， 讓資料在傳輸過程中比較不容易被看到或修改。

HTTP vs HTTPS
項目 HTTP HTTPS
安全性 沒有加密保護 使用 TLS 加密
常見 Port 80 443

🚪 Port

Port 可以想成電腦的「房間號碼」， 用來指定要連接哪一個網路服務。

Port 服務 簡單說明
80 HTTP 一般網頁連線
443 HTTPS 安全網頁連線
22 SSH 遠端登入
3306 MySQL 資料庫服務
02

Inbound、Outbound、防火牆

🔥 Network Security

🔥 Firewall 防火牆

防火牆可以想成網路上的「警衛」。 它會檢查網路連線， 決定哪些連線可以進入或離開電腦。

💡 想像成一棟大樓：

防火牆 = 大樓警衛
Inbound = 有人想進入大樓
Outbound = 大樓裡的人想出去

⬇️ Inbound

Inbound 表示「進入」。 例如外部電腦想要連接你的 Web Server。

⬆️ Outbound

Outbound 表示「出去」。 例如你的電腦連接 Google 網站。

⚙️ 防火牆怎麼設定？

Windows Firewall 可以設定 Inbound Rules 和 Outbound Rules。 使用者可以決定哪些 Port 或服務可以通過。

03

什麼是 CIDR？

🌐 IP Network

CIDR 是 Classless Inter-Domain Routing。 它是一種表示 IP 網路範圍的方法。

💡 最簡單的理解：
CIDR 可以用來表示「一群 IP 所屬的網路範圍」。

📌 例子

192.168.1.0/24

/24 表示前 24 bits 是 Network 部分。

可以簡單理解成： 192.168.1.x 這個網路範圍。

CIDR 簡單理解
/8 很大的網路範圍
/16 中大型網路
/24 常見的小型網路
/32 代表單一 IP
04

DNS、IP、Domain、URL

📖 Internet Address

📍 IP Address

IP Address 是電腦在網路上的地址。 電腦可以透過 IP 找到其他電腦或伺服器。

例如：

142.250.72.14

可以把 IP 想成「房子的地址」。

🌐 Domain Name

Domain Name 是比較容易讓人記住的網站名稱。

例如：

google.com

人類通常比起 IP 更容易記住 Domain Name。

📖 DNS

DNS 是 Domain Name System。 它可以將 Domain Name 找到對應的 IP Address。 

     www.google.com
             │
             ▼
           DNS
             │
             ▼
        IP Address
             │
             ▼
       Google Server
💡 可以這樣記：

Domain = 人類容易記的名字
IP = 電腦使用的地址
DNS = 幫忙查地址的電話簿

🔗 URL

URL 是 Uniform Resource Locator。 它可以想成網路資源的完整地址。

https://www.example.com/index.html
05

URL 範例解析

🔗 Understanding a URL

下面這個 URL 可以拆成幾個不同的部分：

https://www.ncnu.edu.tw:1234/class/upload.php?file=abc
📋 URL 每一部分的意思
URL 部分 名稱 意思
https:// Protocol 使用 HTTPS 通訊協定
www.ncnu.edu.tw Domain 網站的網域名稱
:1234 Port 使用 1234 Port
/class/upload.php Path 伺服器上的路徑與資源
?file=abc Query 查詢參數，file 的值是 abc

🧩 把 URL 拆開來看

HTTPS ＋ Domain ＋ Port ＋ Path ＋ Query
💡 完整理解：

HTTPS → 使用安全的通訊方式
www.ncnu.edu.tw → 找到哪一個網站
1234 → 找到哪一個 Port
/class/upload.php → 找到哪一個資源
file=abc → 傳送的參數 
https://www.ncnu.edu.tw:1234/class/upload.php?file=abc
